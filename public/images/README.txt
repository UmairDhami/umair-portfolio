Put your images here.

- Your photo:        umair.jpg   (then see src/components/Hero.astro to switch it on)
- Project shots:     e.g. lazydayz.jpg, cleaningfairies.jpg ...
                     then set `image: '/images/lazydayz.jpg'` in src/data/projects.js

Anything in /public is served from the site root, so /public/images/umair.jpg
is referenced in code as "/images/umair.jpg".
